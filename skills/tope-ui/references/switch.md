# Switch

## When to use

Use `Switch` for a **single on/off (boolean) setting** in a form: active/inactive, enable notifications, accept terms, etc. The user toggles it by clicking the switch or its label, or with the keyboard (focus and `Space`).

- Value is a `boolean`.

Do **not** use it to choose between several options, use `Select` (`references/select.md`).

## Import

Component should be always imported using useAppForm and used using form.AppField see example below.

```tsx
import { useAppForm } from '@tfilo/tope-ui';
```

Important: must be used inside a TanStack Form field.

`Switch` reads its state via `useFieldContext()`. It has **no `checked`, `value` or `onChange` props**, and it does not work standalone.

- Render it inside a field of a form created with the library's `useAppForm`, registered as a field component.
- Value type is `boolean`. Default value must be `true` or `false`, never `undefined` or `null`.
- Never pass `checked`, `type`, `value`, `onChange`, `onBlur` or `name`. They are omitted from the props type.
- Field name comes from the field context and is set as the checkbox's `name`.

```tsx
const form = useAppForm({
    defaultValues: {
        active: false
    },
    onSubmit: ({ value }) => {
        // value.active is boolean
    }
});

<form.AppField name='active'>
    {(field) => (
        <field.Switch
            id='active'
            data-testid='active'
            label='Active'
        />
    )}
</form.AppField>;
```

Validation is done by TanStack Form validators on the field. `required` is visual only (a star next to the label), so to require `true` (e.g. accepting terms) use a validator:

```tsx
<form.AppField
    name='terms'
    validators={{
        onChange: ({ value }) => (value ? undefined : 'You must accept the terms')
    }}
>
    {(field) => (
        <field.Switch
            label='I accept the terms'
            required
        />
    )}
</form.AppField>
```

## Props

| Prop          | Type                                    | Required | Default                | Description                                                                                                                                            |
| ------------- | --------------------------------------- | -------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `label`       | `string`                                | No       | -                      | Label displayed next to the switch. Clicking it toggles the switch.                                                                                    |
| `required`    | `boolean`                               | No       | `false`                | **Visual only**: shows a red asterisk next to the label. It does not validate and sets neither the native `required` nor `aria-required`.              |
| `error`       | `string`                                | No       | -                      | Externally provided error message. Displayed only when the field has no validator errors, **validator errors take precedence**. Colors the switch red. |
| `disabled`    | `boolean`                               | No       | `false`                | Disables the switch. Styled as disabled.                                                                                                               |
| `readOnly`    | `boolean`                               | No       | `false`                | Value is displayed but cannot be changed.                                                                                                              |
| `id`          | `string`                                | No       | generated by `useId()` | Base id. The real DOM id of the checkbox is `input-{id}` (the label points to it).                                                                     |
| `data-testid` | `string`                                | No       | -                      | Base test id, test ids of the checkbox input, label and error messages derive from it. See [Testing](#testing).                                        |
| other props   | `InputHTMLAttributes<HTMLInputElement>` | No       | -                      | Spread to the hidden checkbox input, e.g. `aria-*`, `title`, `autoFocus`.                                                                              |

Props that are always overridden internally even if passed: `name` (taken from the field), `checked`, `disabled` (as given), `onChange`, `onBlur`, `id` (prefixed). Do not pass `className`, it would replace the classes that visually hide the native checkbox and show it next to the switch.

### Behavior notes

- The native checkbox is visually hidden. The visible switch is a label bound to it, so both the switch and the label text toggle the value.
- The field is marked as touched when the checkbox loses focus. Validator errors are displayed only after that (or after a form submit attempt). The `error` prop is displayed immediately.
- The switch and its messages turn red when there is any error.
- Texts (hidden accessible text of the switch, required star description) come from the library localization (`setLocalization`), Slovak by default.

## Types

```ts
interface BaseProps {
    label?: string;
    error?: string;
    'data-testid'?: string;
}

export interface SwitchProps
    extends
        Omit<InputHTMLAttributes<HTMLInputElement>, keyof BaseProps | 'checked' | 'type' | 'value' | 'onChange' | 'onBlur' | 'name'>,
        BaseProps {}
```

## Testing

All test ids are derived from the `data-testid` prop. In the table `{testid}` is the value passed to `data-testid`; without the prop no test ids are rendered. The checkbox input is visually hidden.

| Element                                                  | data-testid / selector |
| -------------------------------------------------------- | ---------------------- |
| Checkbox input (visually hidden), use it to assert state | `{testid}`             |
| Switch track (visible, click it to toggle)               | `{testid}_switch`   |
| Label text (only when `label` is set)                    | `{testid}_label`       |
| Validator error message (`idx` is zero-based)            | `{testid}_error_{idx}` |
| Message from the `error` prop                            | `{testid}_error_0`     |

Click the visible switch track or label to toggle and assert the state on the checkbox input.

Cypress example:

```ts
cy.get('[data-testid="active_switch"]').click();
cy.get('[data-testid="active"]').should('be.checked');
```

Playwright example:

```ts
await page.getByTestId('active_switch').click();
await expect(page.getByTestId('active')).toBeChecked();
```
